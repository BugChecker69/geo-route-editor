1. システム概要

--------------------------------------------------------------------------------

地図上でウェイポイント（屈折点）をプロットし、ツーリング・ドライブ等の走行ルート

計画、およびドローン等の飛行エリア・経路の策定を行い、各種ナビアプリや外部システム

で利用可能な KML / GPX ファイルを出力・相互インポートするWebアプリケーション。



ローカル環境（file:///）および Webホスティング（GitHub Pages 等）の両方でビルド不要

かつ安定して動作するシングルファイル構成を採用。





2. 主な用途・ユースケース

--------------------------------------------------------------------------------

(1) ツーリング・ドライブ・サイクリング

    - 経由地指定による走行ルート作成（直線接続 / 道路追従スナップ）

    - 総走行距離・区間ごとの距離測定

    - スマートフォンナビアプリ（OsmAnd、Google マイマップ等）や Garmin 機器への

      GPX / KML ルートインポート



(2) ドローン・無人航空機運用（DIPS 2.0 等）

    - 個別申請向け飛行エリア（Polygon）の座標範囲作成

    - 飛行経路（LineString）の策定

    - 高度情報なし（2次元座標 / clampToGround）準拠の KML ファイル生成



(3) 既存ログの確認・編集

    - 過去の走行ログや申請用 KML/GPX の取り込み・再編集





3. アーキテクチャ・技術選定

--------------------------------------------------------------------------------

(1) 構成

    - HTML5 / Vanilla JavaScript による完全シングルファイル構成 (index.html)

    - 外部ビルド環境（Node.js / npm等）不要



(2) 外部ライブラリ・API

    - 地図描画エンジン: Leaflet.js (v1.9.4 CDN)

    - UIスタイリング: Tailwind CSS (CDN)

    - アイコン表示: Font Awesome 6 (CDN)

    - 道路ルーティングAPI: OSRM (Open Source Routing Machine) Driving Public API

    - 地名検索: OpenStreetMap Nominatim API



(3) 背景地図タイル構成

    - 国土地理院 標準地図（デフォルト初期表示: ローカル実行時の403制限回避）

    - 国土地理院 航空写真（オルソ画像）

    - OpenStreetMap (OSM) 標準タイル

    ※レイヤーコントロールよりワンクリックで切り替え可能





4. 機能要件・UI仕様

--------------------------------------------------------------------------------

(1) 地図操作・ポイントプロット

    - 地図上クリックによる新規ウェイポイントの順次追加

    - ピン（マーカー）のドラッグ＆ドロップによる位置微調整

    - 各ポイントへの連番バッジ自動付与



(2) 形状モード (Geometry Mode)

    - ルート / 経路 (Line):

      * 直線接続モード: 屈折点間を最短直線で結ぶ（ドローン・測量・ハイキング向け）

      * 道路スナップモード: OSRM API を介して実際の道路網に追従したルートを補間生成

    - エリア / 面 (Polygon):

      * 始点と終点を自動接続した多角形を描画（外周距離を算出）



(3) 計測・リスト管理

    - 総走行距離 / 外周距離の自動計算（Hubenyの公式に準拠した球面距離算出）

    - 区間距離（直前ポイントからの増分）の表示

    - サイドバーでの経由点一覧テーブル表示

    - 個別削除ボタン / 1つ戻す（Undo） / 全クリア機能



(4) インポート機能

    - KML: <coordinates> タグ内の経度,緯度座標列をパースして地図上に復元

    - GPX: <trkpt>（トラックログ）または <wpt>（ウェイポイント）をパースして復元



(5) エクスポート機能

    - KML 出力:

      * 2次元座標（経度,緯度）形式、高度指定は「clampToGround」

      * Polygon モード時は始点終点を一致させた <LinearRing> 構造を出力

    - GPX 出力:

      * 経由点一覧を <wpt> として出力

      * 道路補間データを含む全軌跡を <trk> / <trkseg> / <trkpt> として出力





5. ファイル出力仕様詳細

--------------------------------------------------------------------------------

[KML 仕様]

  - 形式: OGC KML 2.2 準拠

  - MIMEタイプ: application/vnd.google-earth.kml+xml

  - 特徴: 高度値（Z軸）を含めず、地表固定属性を明記。Google Earth、DIPS 2.0 に適合。



[GPX 仕様]

  - 形式: GPX 1.1 準拠

  - MIMEタイプ: application/gpx+xml

  - 特徴: ウェイポイントとトラックの両方を包含し、Garmin、ナビアプリ双方で認識可能。





6. 今後の拡張検討（バックログ）

--------------------------------------------------------------------------------

1. 標高プロファイル表示

   - 国土地理院 標高APIとの連携による高低差・獲得標高グラフの描画。

2. ルーティングモードの追加

   - 自転車（Bicycle）および徒歩（Foot）プロファイルの追加。

3. 地点メモ・経由地名称の個別編集

   - ウェイポイントごとに任意の名称や説明（給油所、休憩スポット等）を付与する機能。
